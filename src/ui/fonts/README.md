# Bundled fonts

`PrintChar21-2020.ttf` is the unmodified 2020 release of **Print Char 21** by Rebecca Bettencourt / Kreative Software. It is sourced from the official [Ultimate Apple II Font](https://www.kreativekorp.com/software/fonts/apple2/) download and provides the 40-column text and MouseText glyphs used by the Retro control panel.

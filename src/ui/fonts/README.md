# Bundled fonts

`PrintChar21.woff2` provides the 40-column text and MouseText glyphs used by the emulator display and Retro control panel. **Print Char 21** is by Rebecca Bettencourt / Kreative Software and is sourced from the official [Ultimate Apple II Font](https://www.kreativekorp.com/software/fonts/apple2/) download.
